# FuzzyFlow
FuzzyFlow is a smart irrigation simulator by Uday Tejan (LIT2024057) for Soft Computing. Built on a Mamdani Fuzzy Inference System, it evaluates Soil Dryness and Sunlight Intensity through a 9-rule base to compute precise watering duration (0-30 min) via centroid defuzzification, backed by interactive UI controls and physics animations.
